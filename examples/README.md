# 示例画廊 (Example Gallery)

[简体中文](../README.md) · [English](../README.en.md)

每个精选示例均包含一张高分辨率确认预览大图。图中的红色十字仅用于标识光标真实点击热点（Hotspot），不会包含在实际安装的鼠标图案中。

Each curated example contains one high-resolution approval preview. The red crosses explain real pointer hotspots and are not part of installed cursor artwork.

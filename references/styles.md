# Cursor art styles

Use one character design, palette, outline weight, and accessory system through the complete set. Let the pose and emotion change by state; never put the character inside an unrelated cursor silhouette.

## retro-pixel

Match a polished 16-bit or 32-bit game UI: strong 1–2 pixel outline, intentional dithering only when it survives downsampling, bright palette blocks, and expressive tiny character portraits. Use a grid-constrained silhouette, no blur, and no smooth gradients. The normal arrow, I-beam, hand, and resize arrows must remain obvious before character details are added.

## chibi-anime

Use compact Q-version anime proportions: large expressive eyes, rounded head, small body or hands, one recognisable accessory, and distinct emotions for waiting, busy, forbidden and help. Prefer clean sticker-like outlines and a coordinated pastel or saturated palette. Use the character as the cursor itself or as a coherent pose, not a face pasted onto a hand.

## abstract-expression

Use a deliberately expressive graphic concept: exaggeration, visual metaphor, surreal object, deadpan face, folk-art-like figure, absurd reaction, or meme-like timing. Humor is optional, not mandatory. Keep it original, readable, and visually consistent. Make the meaning come from pose, expression, silhouette, and props; do not depend on tiny captions, logos, or copyrighted screenshots.

## Character input

If the user provides a reference image, preserve its recognisable visual traits while adapting it to each state. If they provide only a named IP or character, use the name as a high-level style/character brief; create fresh cursor artwork and never present it as official merchandise. Ask only when a missing choice would materially change the result.

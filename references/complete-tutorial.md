# 鼠标皮肤完整使用教程（交付时必附）

本教程面向第一次安装鼠标皮肤的用户。预览确认后、打包前，先确认用户使用的是 macOS 还是 Windows；只制作并交付确认平台的安装包，不把两个平台放在同一个压缩包里。交付时，先写出实际压缩包和主题文件的名称，再给出确认平台对应的小节。

## 交付前必须说明

1. 主题预览已经确认；安装包中的图案、热点和八个核心状态与预览一致。
2. 鼠标皮肤不会把所有软件里的所有鼠标形状都变掉。正常箭头、文字输入、链接/按钮、窗口边缘拉伸最容易见到；忙碌、后台运行、不可用、手写等由软件自行决定，可能很少出现。
3. 不要把 macOS 登录密码、Windows 密码或验证码发给任何人。只有系统弹出的正常授权窗口才由用户自己输入密码。

## macOS：从下载到应用

适用于 macOS 15 或更高版本。macOS 使用 `.cape` 文件，需要先安装 Mousecape SwiftUI；Windows 的 `.cur` 文件不能导入到 Mousecape。

1. 下载交付包，双击 `.zip` 解压。把主题文件 `<主题名>.cape` 保留在解压后的文件夹中。
2. 本主题包**不得打包或再分发 Mousecape**。请由用户自己打开官方上游发布页 <https://github.com/sdmj76/Mousecape-swiftUI/releases>，下载最新正式 Release。下载后解压，把 `Mousecape.app` 拖进 **应用程序（Applications）** 文件夹。Mousecape 有独立的非商业/禁止再分发许可证，商业使用前必须自行确认许可。
3. 到 **应用程序** 打开 Mousecape。若看到“无法验证开发者”或“无法打开”的提示，按住 `control` 键点按 Mousecape，选择 **打开**，然后在第二个确认框再选择 **打开**。不要使用旧的 Mousecape 1813 版本。
4. Mousecape 第一次启动若显示 Helper、Install Helper 或类似的安装提示，按界面完成即可。只有 macOS 自己弹出的密码框才输入本机登录密码。
5. 导入主题：优先把 `<主题名>.cape` 直接拖进 Mousecape 窗口；拖不进去时，双击 `.cape` 文件，或在 Mousecape 的 **File / 文件** 菜单选择 **Import / 导入**。主题名称出现在左侧列表，才表示导入成功。
6. 在列表中点选主题，再使用 **Apply / 应用**（有的版本是右键主题后选择 Apply）。看到主题旁出现已应用标识，或鼠标箭头立即变化，即表示成功。
7. 如果刚应用时箭头没有刷新，先退出并重新打开 Mousecape，再次应用；仍无变化时按该版本界面提示完成 Helper 安装，然后重新应用。

## Windows 10/11：从解压到应用

Windows 不需要 Mousecape，使用包内的 `.cur` 文件和安装脚本。此包只修改当前 Windows 账户的鼠标设置，不需要管理员权限。

1. 右键交付包，选择 **全部解压缩**。把整个 Windows 主题文件夹移动到不会删除的位置，例如“文档/鼠标皮肤/主题名”。**安装后不能移动或删除这个文件夹**，因为 Windows 会持续从这里读取 `.cur` 文件。
2. 打开该文件夹，确认里面有 `install-current-user.ps1`、`restore-default.ps1` 和多个 `.cur` 文件。
3. 右键 `install-current-user.ps1`，选择 **Run with PowerShell（使用 PowerShell 运行）**。Windows 11 如未看到它，先选择 **显示更多选项**。只在文件夹确实是本主题包时确认系统提示。
4. 安装脚本只写入当前用户的 `HKCU\Control Panel\Cursors`，不会索取管理员权限。鼠标通常会立刻刷新；没有刷新就注销 Windows 后重新登录。
5. 若 Windows 拦截脚本，先确认文件来自本主题包，再右键脚本选择 **属性**；如果底部有“解除锁定”，勾选并点击确定，再重试。不要下载来源不明的同名脚本。

## 安装后立刻验证

按下面顺序检查，能快速确认主题有没有真正应用，而不是只看到某一个图案。

| 要验证的状态 | 最容易测试的位置 | 预期 |
| --- | --- | --- |
| 正常选择 | 桌面、Finder 或资源管理器的空白处 | 主题箭头 |
| 文本输入 | 备忘录、浏览器地址栏、文本编辑器 | I 形文本光标 |
| 链接/按钮 | 浏览器里可点击的链接或按钮 | 手形/动作光标 |
| 水平拉伸 | Finder/资源管理器窗口的左、右边缘 | 左右拉伸光标 |
| 垂直拉伸 | Finder/资源管理器窗口的上、下边缘 | 上下拉伸光标 |
| 斜向拉伸 | 窗口四个角 | 对角拉伸光标 |

以下状态不是安装失败的判断标准：

- **忙碌 / 后台运行**：通常只在软件加载、打开文件或系统短暂处理时出现，很多应用用自己的加载动画代替它。
- **不可用**：许多禁用按钮仍然保持普通箭头；只有应用主动请求“禁止”光标时才会显示。
- **手写、帮助、精确选择**：属于低频状态，浏览器、设计软件或特定应用才可能请求。

如果正常箭头、文本和窗口边缘都没有变化，才按下一节排查。

## 常见问题与解决方法

| 现象 | macOS 解决方法 | Windows 解决方法 |
| --- | --- | --- |
| 主题导入后没有变化 | 重新打开 Mousecape，完成界面中的 Helper 安装提示后再 Apply；确认导入的是 `.cape` 而不是 zip。 | 确认主题文件夹没有被移动；重新运行 `install-current-user.ps1`，然后注销/登录。 |
| 只在部分软件里变化 | 正常：应用自己决定请求哪种光标；用 Finder 的文本和窗口边缘按上表验证。 | 正常：应用自己决定角色；用资源管理器、记事本和浏览器链接按上表验证。 |
| macOS 提示版本不能打开 | 删除旧版 Mousecape，改用最新 SwiftUI 版本；必要时 `control`-点击 → 打开。 | 不适用。 |
| Windows 看不到 Run with PowerShell | 先点“显示更多选项”；若被拦截，打开文件属性并解除锁定后重试。 | 同左。 |
| 光标看起来模糊或点击偏移 | 不要继续使用旧主题；回传截图和所用系统版本，让制作者重新检查 Retina 图层与热点。 | 回传截图和所用缩放比例，让制作者重新检查 `.cur` 热点和尺寸。 |

macOS 的鼠标颜色、对比度或某些应用自绘光标也可能覆盖 Mousecape。遇到“某个 app 永远不变”，先用 Finder 或 Safari 的普通网页验证；若这些位置正常，说明主题已安装，那个 app 本身不开放该状态给系统替换。

## 恢复默认鼠标

### macOS

回到 Mousecape，选中系统默认鼠标或使用该版本界面中的 **Reset / 恢复系统光标**，再点击 Apply。若只是想停用这个主题，不必删除 `.cape` 文件；保留它可以之后随时重新应用。

### Windows

在安装包原来的文件夹中，右键 `restore-default.ps1`，选择 **Run with PowerShell**，然后注销/登录（若未立刻刷新）。这个脚本只移除该主题写入的 15 个当前用户鼠标角色；如果用户之后手动设置过其他鼠标方案，应改用 **控制面板 → 鼠标 → 指针** 选择想保留的方案，而不要运行恢复脚本。

## 制作者的最终回复格式

交付给用户时必须使用以下顺序，而不是只给出文件路径：

1. 先说明已生成的 Mac `.cape`、Windows 文件夹/zip、预览图各是什么。
2. 说明用户当前可用的验证状态和低频状态的限制。
3. 紧接着贴出与用户平台对应的“从下载到应用”“安装后立刻验证”“恢复默认鼠标”步骤；不要求用户另行阅读文档或猜测文件名。
4. 若用户安装时发来截图，先根据截图定位到本教程的具体步骤，再给单一步骤的修复，不让用户从头重做。
